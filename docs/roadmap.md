# Roadmap del repositorio

## Tarea 3

- API REST bancaria con Spring Boot.
- Seguridad JWT.
- Validación y manejo global de errores.
- Pruebas y cobertura mínima.

## Tarea 4

- Procesamiento concurrente de transacciones.
- `ExecutorService`.
- Kafka o simulación controlada.
- Logging estructurado.

## Proyecto final

- Plataforma bancaria completa.
- Módulos de clientes, cuentas, movimientos y reportes.
- Seguridad JWT y despliegue con Docker.
- Documentación técnica y pruebas automatizadas.
