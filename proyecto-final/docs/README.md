## Diagramas UML

Los diagramas UML del proyecto se encuentran en `docs/diagrams` en formato PlantUML (`.puml`).

Para generar imagenes PNG localmente, coloca `plantuml.jar` en la raiz del proyecto y ejecuta:

```bat
cd proyecto-final
docs\generate-diagrams.bat
```

El script genera PNGs en `docs/images/diagrams`.
