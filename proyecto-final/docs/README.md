# Documentación de `proyecto-final`

## Diagramas UML
Los diagramas UML del proyecto se encuentran en `docs/diagrams` en formato PlantUML (.puml).
Para generar imágenes PNG localmente, coloca `plantuml.jar` en la raíz del proyecto y ejecuta:

```bat
cd proyecto-final
docs\generate-diagrams.bat
```

Generará PNGs en `docs/images/diagrams`.
