# Uso de logos e imágenes

Las imágenes y logos se encuentran en `docs/images/`.

Ejemplo (Markdown):

![Logo del banco](images/logo.png)

Incluye estas imágenes en la portada del `README.md` o en la documentación HTML generada.

Si quieres que las imágenes estén disponibles en la aplicación Spring Boot, copia los archivos a `src/main/resources/static/images`.
