Resumen y guía — Tarea 4

Proyecto de ejemplo para procesar transacciones en paralelo y publicar resultados en Kafka.

Cómo ejecutar

  1. Levantar Kafka: docker compose up -d
  2. Ejecutar pruebas: mvn clean test
  3. Iniciar servicio: mvn spring-boot:run

Qué incluye

  • Procesamiento concurrente con `ExecutorService`
  • Control de errores por transacción
  • Endpoints HTTP para enviar lotes
